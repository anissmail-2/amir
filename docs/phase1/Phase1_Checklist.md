## Project Selected

**Smart Urban Farming Management System (SUFMS)**

An AI-powered platform for urban farmers featuring:
- IoT sensor monitoring
- AI crop recommendations and pest detection
- Resource optimization (water, fertilizer)
- Integrated marketplace
- Knowledge hub and community features

## Key Statistics Included

- Market size: $13.8B → $22.5B (2023-2028)
- Water savings: 40% reduction
- Yield increase: 30-50% improvement
- Time savings: 20+ hours/week
- 15 million urban farmers worldwide

## Methodology Chosen

**Agile Scrum** - Justified for:
- Iterative development aligned with 5 phases
- Flexibility for changing requirements
- Team collaboration through sprints
- Risk mitigation through continuous integration
- Academic alignment with UML documentation

## Technologies Selected

- **Frontend:** React.js, React Native
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL, InfluxDB, Redis
- **AI/ML:** TensorFlow, OpenAI GPT API
- **IoT:** MQTT, Arduino/Raspberry Pi
- **Cloud:** AWS (EC2, S3, Lambda)

## Benchmark Comparison

Compared against:
- FarmBot (hardware-focused)
- Agrilyst (commercial greenhouses)
- Grobo (closed indoor system)

**Our competitive advantages:**
- Holistic integration (monitoring + AI + marketplace)
- Hardware agnostic (open platform)
- Accessible pricing (freemium model)
- Community-centric features
