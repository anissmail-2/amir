# Smart Urban Farming Management System (SUFMS)

**SWE 401 Course Project - Fall 2025**

An AI-powered cloud-based platform for urban farmers to optimize crop management, resource usage, and marketplace connectivity.

## 📋 Project Overview

This repository contains the complete deliverables for the SWE 401 Software Engineering course project at the College of Engineering.

**Project Goal:** Develop an intelligent farming management system that combines IoT monitoring, AI-powered decision support, and marketplace integration to help urban farmers maximize yield and sustainability.

## 🎯 Key Features

- **Smart Monitoring:** Real-time IoT sensor data (soil, temperature, humidity, pH)
- **AI-Powered Insights:** Crop recommendations, pest detection, yield prediction
- **Resource Optimization:** Intelligent irrigation and fertilizer scheduling
- **Marketplace:** Direct farmer-to-consumer sales platform
- **Knowledge Hub:** AI chatbot, tutorials, and community forums
- **Sustainability Tracking:** Carbon footprint and resource efficiency metrics

## 🛠️ Technology Stack

**Frontend:**
- React.js (Web), React Native (Mobile)
- Material-UI, Tailwind CSS
- Chart.js, D3.js

**Backend:**
- Node.js with Express.js
- RESTful API + GraphQL
- JWT Authentication

**Database:**
- PostgreSQL (relational data)
- InfluxDB (time-series sensor data)
- Redis (caching)

**AI/ML:**
- TensorFlow/PyTorch
- OpenAI GPT API (chatbot)
- Python (Flask microservices)

**IoT:**
- MQTT protocol
- Arduino/Raspberry Pi
- AWS IoT Core

**Cloud & DevOps:**
- AWS (EC2, S3, Lambda)
- Docker, Kubernetes
- GitHub Actions (CI/CD)
